## Get Release

## Browse Releases

<Route method="GET">/release</Route>

Browse and filter releases.

#### Query String Params [!toc]

<FieldTable
  fields={{
    limit: {
      description: "Amount of releases to return (max 20)",
      type: "integer",
      default: "20",
    },
    offset: {
      description: "Amount of releases to skip",
      type: "integer",
      default: "0",
    },
    sort: {
      description:
        "Field name to sort by. Prefix with `-` to use descending order",
      type: "string",
      default: "",
    },
    columns: {
      description:
        "Fields to include in the response. Excluded fields will still be present but use their default values",
      type: "array of strings",
      default: `<details><summary>Best effort list of defaults</summary>["ArtistsTitle", "CatalogID", "CopyrightPLine", "CoverFileID", "EffectiveGenrePrimary", "EffectiveGenreSecondary", "FeaturedArtistsTitle", "GRid", "ID", "LabelID", "ReleaseDate", "ReleaseDateTimezone", "Title", "Type", "UPC", "Version"]</details>`,
    },
    creator_safe: {
      description: "Use copyright safe mode",
      type: "boolean",
    },
    artist_id: {
      description:
        "Filter for releases by specific artists. Value is the artist's UUID",
      type: "array of strings",
    },
    associated_artist_id: {
      description:
        'Filter for releases that an artist is featured on aka "Appears on". Value is the artist\'s UUID',
      type: "string",
    },
  }}
/>

#### Response Body [!toc]

<FieldTable paginatedData="array of [release](#release-object) objects" />

## Get Release Artists

<Route method="GET">/release/[\{Release.ID}](#release-object)/artists</Route>

## Get Release Cover Art

<Route method="GET">/release/[\{Release.ID}](#release-object)/cover</Route>

For size and format options, see [Image Formatting](../reference#image-formatting).
