      required: true,
    },

## Get Genre

<Route method="GET">/genre/[\{Genre.ID}](#genre-object)</Route>

Get a genre by ID. Returns a [genre](#genre-object) object.

## Get Genre Image

<Route method="GET">
  /file/[\{Genre.PreferredImageFileID}](#genre-object)/cover
</Route>

Redirects to the original image file.
For size and format options, see [Image Formatting](../reference#image-formatting).
