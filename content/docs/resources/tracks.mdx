## Stream Track

<Route method="GET">/track/[\{Track.TrackID}](#track-object)/stream</Route>

Redirects to a streamable audio file. The file depends on the authenticated user.

| User type       | Format               | Description                         |
| --------------- | -------------------- | ----------------------------------- |
| Unauthenticated | `MP3_128_NC_PREVIEW` | A short preview of the track        |
| Free account    | `MP3_128_NC`         | 128kbps .mp3 file with no cover art |
| Premium account | `MP3_320_NC`         | 320kbps .mp3 file with no cover art |

## Download Track

<Route method="GET">
  /release/[\{Track.ReleaseID}](#track-object)/track/[\{Track.TrackID}](#track-object)/encoding
</Route>

Download a track in the desired format.

#### Query String Params [!toc]

<FieldTable
  fields={{

      description: "The desired file format",
      type: "string",
      required: true,
    },
    filename: {
      description: "The file name",
      default: "The original file name",
      type: "string",
    },
  }}
/>

##### Downloadable formats [!toc]

| Format    | Description                                                                                                             |
| --------- | ----------------------------------------------------------------------------------------------------------------------- |
| `MP3_320` | 320kbps .mp3 file. Lossy compression at high quality with smaller file sizes                                            |
| `FLAC`    | .flac (Free Lossless Audio Codec) file. Lossless compression with bigger file sizes                                     |
| `WAV`     | .wav (Waveform Audio File Format) file. Uncompressed and lossless with the biggest file size. Does not include metadata |

      required: true,

    SignedURL: {
      description: "The link to the downloadable file",
      type: "string",
      required: true,
    },
  }}
/>

Otherwise redirects directly to the `SignedURL`
