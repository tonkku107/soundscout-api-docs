## Artist Object

<FieldTable
  fields={{
    Description: {
      description: "Artist's bio",
      type: "string",
      required: true,
    },
    Hidden: {
      description: "Whether the artist profile is hidden",
      type: "boolean",
      required: true,
    },
    ID: {
      description: "UUID of the artist",
      type: "string",
      required: true,
    },
    Images: {
      description: "Images of the artist",
      type: "[artist images](#artist-images-object) object",
      required: true,
      nullable: true,
    },
    Links: {
      description: "Links to the artist's social media profiles",
      type: "array of [artist link](#artist-link-object) objects",
      required: true,
      nullable: true,
    },
    MemberIDs: {
      description:
        "UUIDs of artist profiles that have been merged into this one",
      type: "array of strings",
      required: true,
    },
    Name: {
      description: "The artist's name",
      type: "string",
      required: true,
    },
    Tags: {
      description: "Tags for the artist",
      type: "array of strings",
      required: true,
      nullable: true,
    },
    URI: {
      description:
        "The slug to the artist's profile page. `soundscout.com/player/artists/{URI}`",
      type: "string",
      required: true,
    },
  }}
/>

## Get Artist

<Route method="GET">/artist/[\{Artist.ID or Artist.URI}](#artist-object)</Route>

Get an artist by ID or URL slug. Returns an [artist](#artist-object) object.

<FieldTable

  }}

## Browse Artists

<Route method="GET">/artist</Route>

Browse all artists.

<FieldTable
  fields={{
    limit: {
      description: "Amount of artists to return (max 20)",
      type: "integer",
      default: "20",
    },
    offset: {
      description: "Amount of artists to skip",
      type: "integer",
      default: "0",
    },
    sort: {
      description:
        "Field name to sort by. Prefix with `-` to use descending order. `Popularity` is also an option despite not being a visible field",
      type: "string",
      default: "",
    },
    columns: {
      description:
        "Fields to include in the response. Excluded fields will still be present but use their default values",
      type: "array of strings",
      default: `All fields`,
    },
  }}
/>

#### Response Body [!toc]

<FieldTable paginatedData="array of [artist](#artist-object) objects" />

## Browse Artist Tracks

<Route method="GET">/artist/[\{Artist.ID or Artist.URI}](#artist-object)/catalog</Route>

A version of the [Browse Tracks](./tracks#browse-tracks) endpoint for artists.
See the aforementioned endpoint for the parameters and response information.

## Browse Artist Releases

<Route method="GET">/artist/[\{Artist.ID or Artist.URI}](#artist-object)/releases</Route>

A version of the [Browse Releases](./releases#browse-releases) endpoint for the artist's own releases.
See the aforementioned endpoint for the parameters and response information.

## Browse Artist's Appeared On Releases

<Route method="GET">/artist/[\{Artist.ID or Artist.URI}](#artist-object)/appears-on</Route>

A version of the [Browse Releases](./releases#browse-releases) endpoint for releases the artist appears on.
See the aforementioned endpoint for the parameters and response information.

## Get Artist Cover Image

<Route method="GET">/artist/[\{Artist.ID}](#artist-object)/cover</Route>

Redirects to the original cover image file.
For size and format options, see [Image Formatting](../reference#image-formatting).

#### Query String Params [!toc]

<FieldTable
  fields={{
    fileID: {
      description: "The UUID of the file from `Images.cover`",
      type: "string",
    },
  }}
/>

## Get Artist Cover Image Info

<Route method="GET">/artist/[\{Artist.ID}](#artist-object)/cover-info</Route>

Obtain metadata about the source of the cover image.

#### Response Body [!toc]

<FieldTable
  fields={{
    FileID: {
      description: "The UUID of the image file if source is `upload`",
      type: "string",
      required: true,
    },
    Source: {
      description:
        "The source of the cover image. `upload` for a file on SoundScout's platform. `spotify` for Spotify's CDN",
      type: "string",
      required: true,
    },
  }}
/>
