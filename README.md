# SoundScout API Documentation

Unofficial community documentation for the api of [SoundScout](https://soundscout.com).
The documentation can be viewed [here](https://tonkku107.github.io/soundscout-api-docs).

## Contributing
Contributions in pull requests are welcome! You can add your name to the contributors section on the front page with your first contribution.

The documentation itself can be found in the `content` folder as [MDX](https://mdxjs.com/) files ([Markdown](https://github.github.com/gfm) with some [React](https://react.dev/) components). The rest is setting up the website with [Fumadocs](https://www.fumadocs.dev/).

For a local preview use `yarn dev` and you can access the documentation at `http://localhost:3000`
